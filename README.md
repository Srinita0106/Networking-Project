
# Career Quest 🚀

**Networking-Enabled Job Recommendation System**
Enhancing Efficiency and Personalization with **UDP Communication**

---

## 📌 Project Overview

Career Quest is a **personalized career recommendation system** that leverages **LinkedIn profiles** to provide tailored career opportunities. By analyzing a user’s education, skills, work experience, and preferences, the system identifies individual strengths and matches them with job postings.

What makes this project unique is the integration of **networking concepts (UDP, multicast, checksum verification, email broadcasting)** to enhance data transmission, collaboration, and communication.

The system is designed to:

* Extract and analyze LinkedIn profile data.
* Recommend relevant job roles using **job scraping and skill matching**.
* Enable **UDP-based networking** for fast, lightweight data transfer.
* Provide **email communication** and **group collaboration** features.
* Foster skill-based networking via **multicasting**.

---

## 🎯 Objectives

* Assist users in exploring personalized career opportunities.
* Enhance efficiency in data handling using **UDP sockets**.
* Provide seamless **email communication** and secure transmission with checksum.
* Enable **collaborative opportunities** through skill-matching and group communication.

---

## 🛠️ Tech Stack

### **Programming Languages**

* **Java** (Core implementation, GUI with Swing, UDP networking)
* **Python** (Email broadcasting & scripting integration)

### **Networking Concepts**

* **UDP Sockets** for client-server communication
* **Checksum (CRC-4)** for data integrity verification
* **Multicast & Broadcast** for group messaging
* **Packet Inspection** (IP header extraction for analysis)

### **APIs Used**

* **LinkedIn Profile Data API** (via RapidAPI)
* **LinkedIn Jobs Search API**

### **Frontend / GUI**

* **Java Swing** (User-friendly interfaces for input, server logs, and communication windows)

### **Data Handling**

* **JSON Parsing** for LinkedIn profile & job response handling
* **Job Scraping Module** to extract job details such as:

  * Job Title, Company Name, Job URL
  * Location, Posted Date, Normalized Company Name

---

## ⚙️ Key Features

✅ **LinkedIn Profile Analysis** – Extracts data like education, skills, work experience, and connections.

✅ **Personalized Job Recommendations** – Suggests the most suitable role based on skills.

✅ **UDP Client-Server System** – Efficient transfer of LinkedIn URL and job results.

✅ **Job Scraping & Insights** – Gathers job postings, titles, companies, and trends.

✅ **Email Communication** – Enables sending messages with checksum verification for reliability.

✅ **Multicast Networking** – Skill-based group communication & collaboration opportunities.

✅ **Secure Transmission** – Implements **CRC checksum validation** for error detection.
